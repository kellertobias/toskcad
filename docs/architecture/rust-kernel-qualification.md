The remaining entries below track feature, exchange, desktop and package qualification; the default change does not complete those gates. The product owner accepts failures of tests that require OpenCascade during this migration. Rust feature failures remain open; an unavailable-OpenCascade diagnostic alone does not establish feature parity. Explicit OpenCascade comparisons are optional evidence.
